# NPC 角色设定圣经

本文档整理第一章 20 个 NPC 的基础设定、玩法功能和场景匹配。NPC 都是帅气或漂亮的拟人动物，公开身份用于玩家初见判断，真实气质用于 LLM 对话风格，真实立场只作为系统隐藏信息。

## 设计原则

- 每个 NPC 必须同时服务三件事：提供情报、制造关系判断、参与法器统治循环。
- 公开身份要能自然引出喜欢话题，喜欢话题要能帮助玩家提升好感度。
- 真实立场保持隐藏；NPC 是否说真话由其对玩家的敌友判断决定。
- 场景不是装饰，而是该 NPC 的行动地点和情报来源。
- 所有 NPC 视觉遵循高对比扁平撞色、粗黑手绘勾边、强剪影、少量大色块细节。

## 现有 NPC

### npc_fox：绯尾侯爵
- 公开身份：夜市贵族掮客，喜欢把秘密包装成礼物。
- 真实气质：优雅、算计、乐于经营人情债。
- 喜欢话题：礼节、债契、夜市。
- 情报功能：引出谎言来源和债务线索。
- 玩法功能：高魅力中立角色，可被邀请但代价高。
- 视觉关键词：绯红尾巴、贵族披肩、礼盒与债券、红金撞色。

### npc_crow：墨羽书记官
- 公开身份：旧档案馆书记官，记住别人以为烧掉的字。
- 真实气质：冷硬、记仇、擅长把真相写成陷阱。
- 喜欢话题：档案、墨水、规矩。
- 情报功能：旧王朝、名单和被毁档案。
- 玩法功能：高攻击敌方角色，几乎不可邀请。
- 视觉关键词：黑羽、墨瓶、烧焦目录、青绿反光。

### npc_deer：白枝使节
- 公开身份：温和外交官，句子像祝福也像警告。
- 真实气质：克制、怜悯、擅长用礼法保护盟友。
- 喜欢话题：礼节、和平、花园。
- 情报功能：族群禁忌、外交誓约和接头人判断。
- 玩法功能：友方支援角色，邀请成功收益高。
- 视觉关键词：白枝鹿角、停战铃、花圃缎带、白金与红花。

### npc_snake：青鳞药师
- 公开身份：贩卖药剂和解药的中立线人。
- 真实气质：谨慎、逐利、只相信可交换的证据。
- 喜欢话题：药价、毒理、交换。
- 情报功能：夜市尊重什么、药剂真伪和交易风险。
- 玩法功能：中立情报商，暗杀攻防较高。
- 视觉关键词：青鳞、药瓶、尖角橱窗、毒绿与深红。

### npc_wolf：铁颌军官
- 公开身份：夜市边门军官，习惯把怀疑说成命令。
- 真实气质：警惕、守约、相信军纪胜过传闻。
- 喜欢话题：军纪、边门、名单。
- 情报功能：法器性质、边门检查和真实交易地点。
- 玩法功能：友方战斗角色，正面攻防强。
- 视觉关键词：狼颌轮廓、誓刃、检查口、黄黑警戒块。

## 新增 NPC

### npc_moth_lamplighter：月蛾点灯人
- 公开身份：夜市灯队修灯工，负责点亮月骨灯。
- 真实气质：温和、迟疑、记忆力惊人，害怕强光。
- 喜欢话题：月光、灯火、屋顶。
- 情报功能：谁在灯熄灭时离开、屋脊跟踪路线。
- 玩法功能：友方记忆型角色，可补足遗漏证言。
- 视觉关键词：蛾翼斗篷、圆眼护目镜、点灯杆、月黄与青绿。

### npc_rat_debt_runner：碎齿债跑
- 公开身份：替贵族递送债券和抵押物的夜市跑腿。
- 真实气质：机灵、贪小利、怕死但嘴硬。
- 喜欢话题：债券、跑腿、价码。
- 情报功能：市场债务链和暗号交换。
- 玩法功能：中立交易角色，低门槛透露小线索。
- 视觉关键词：尖鼻、斜挎债袋、短披风、红黄票据。

### npc_lynx_mask_tailor：猞猁面具裁缝
- 公开身份：制作假面和伪装衣饰的裁缝。
- 真实气质：审美锋利，说话像剪刀，讨厌粗糙谎言。
- 喜欢话题：假面、裁剪、体面。
- 情报功能：识别伪装和身份卡破绽。
- 玩法功能：中立鉴别角色，帮助判断身份误认。
- 视觉关键词：尖耳、剪刀袖口、半张面具、品红与青蓝。

### npc_owl_court_astrologer：夜枭宫廷星卜师
- 公开身份：旧王族留下的星象顾问。
- 真实气质：慢、冷、看似迷信但擅长统计。
- 喜欢话题：星图、概率、旧礼。
- 情报功能：旧王族、仪式和误导检测。
- 玩法功能：敌方误导角色，常用概率话术掩盖目的。
- 视觉关键词：圆形眼盘、星图披肩、短杖、深紫黑与金色符号。

### npc_boar_gate_supplier：铁鬃军需商
- 公开身份：为边境守军供给食物、皮革和短刃。
- 真实气质：粗鲁、讲信誉、讨厌欠账不还。
- 喜欢话题：货箱、军需、清算。
- 情报功能：边境军官与夜市商人的物资线。
- 玩法功能：中立资源角色，交易和赠送收益明显。
- 视觉关键词：宽肩、獠牙、货箱背带、橙红与电蓝。

### npc_gecko_wall_listener：壁纹听者
- 公开身份：修补墙缝和屋顶瓦片的工匠。
- 真实气质：存在感低、听力敏锐，把真话藏在玩笑里。
- 喜欢话题：墙缝、雨声、玩笑。
- 情报功能：墙后密谈和暗巷埋伏。
- 玩法功能：友方监听角色，适合提供交叉验证。
- 视觉关键词：细长身体、吸盘手套、墙纹披风、荧光绿与紫黑。

### npc_swan_embassy_duelist：白羽礼剑士
- 公开身份：使馆花园的仪式剑术教师。
- 真实气质：优雅、傲慢、把决斗当礼仪。
- 喜欢话题：礼剑、荣誉、决斗。
- 情报功能：外交礼法和公开决斗规则。
- 玩法功能：敌方正面对抗角色，决斗风险高。
- 视觉关键词：长颈弧线、白羽肩饰、细剑、白金与猩红。

### npc_panther_silent_guard：黑豹静卫
- 公开身份：档案馆夜间守卫。
- 真实气质：沉默、专业、只相信可验证的行动。
- 喜欢话题：证据、巡逻、出入记录。
- 情报功能：档案馆出入见证和地下入口。
- 玩法功能：友方防御角色，需要行动证明才会亲近。
- 视觉关键词：黑色剪影、青蓝眼光、短披肩、红色警戒带。

### npc_frog_poison_taster：金喉试毒师
- 公开身份：药铺雇佣的试毒与试药专家。
- 真实气质：乐观、神经质、对危险兴奋。
- 喜欢话题：试药、毒理、解药。
- 情报功能：药剂真假、毒理来源和交易风险。
- 玩法功能：中立风险提示角色，可降低错误判断代价。
- 视觉关键词：圆形身体、大喉囊、药勺、毒绿与金黄。

### npc_hare_false_messenger：裂耳假信使
- 公开身份：在夜市、边门、使馆之间传递急信。
- 真实气质：紧张、速度快，常带来真假混杂的消息。
- 喜欢话题：急信、路线、桥。
- 情报功能：制造时间压力，暴露消息调包。
- 玩法功能：敌方扰动角色，会加速错误线索传播。
- 视觉关键词：破口长耳、信筒、窄腿剪影、蓝紫与热红。

### npc_bat_roof_informant：夜翼檐探
- 公开身份：替夜市屋顶商贩巡视风向和灯号的檐探。
- 真实气质：轻声、敏锐、喜欢倒挂着听完一整段谎话。
- 喜欢话题：屋檐、风向、灰烬地图。
- 情报功能：屋顶路线、灰烬地图和远处目击证言。
- 玩法功能：友方侦察角色，适合校验地点类情报。
- 视觉关键词：披翼斗篷、大耳、灰烬地图碎片、蓝绿夜光。

### npc_badger_oath_notary：獾纹誓约公证人
- 公开身份：地下交易柜台的誓约公证人。
- 真实气质：严肃、耐心、相信每一句话都应被称重。
- 喜欢话题：誓约、称量、代价。
- 情报功能：血誓、债契和法器代价。
- 玩法功能：中立规则角色，可解释交换与赠送风险。
- 视觉关键词：獾纹脸、骨秤、印章、厚黑轮廓与短促金光。

### npc_eel_drain_smuggler：暗渠鳗走私客
- 公开身份：边境排水门的秘密通行掮客。
- 真实气质：滑不留手、怕光、擅长把背叛伪装成捷径。
- 喜欢话题：暗渠、通行费、红绳结。
- 情报功能：走私路线和边门漏洞。
- 玩法功能：敌方诱导角色，会提供高收益但危险的建议。
- 视觉关键词：细长鳗身、湿亮披风、铁栅、绿水反光。

### npc_goat_bell_keeper：角铃桥守
- 公开身份：看守使馆铃桥与回声镜亭的礼仪守桥人。
- 真实气质：固执、守规、会用重复话语测试来客。
- 喜欢话题：铃声、桥、回声。
- 情报功能：门槛禁忌、转述验证和重复证词。
- 玩法功能：中立验证角色，能帮助确认他人话语是否被转述。
- 视觉关键词：弯角、铃绳、镜面柱、白金与青光。

### npc_mantis_knife_judge：螳臂刀审
- 公开身份：边门瞭望塔上的临时审判官。
- 真实气质：冷峻、精确、相信清算必须快到看不清。
- 喜欢话题：审判、名单、瞭望。
- 情报功能：政治清洗、牺牲名单和边门观察记录。
- 玩法功能：敌方处刑角色，暗杀与正面攻击都危险。
- 视觉关键词：螳螂刀臂、红军旗、探照灯、青蓝夜空。
