Liars Land / Action Animation Plan

行动先演出，结果后揭示

玩家或 NPC 执行动作后，先进入全屏行动动画。动画会按真实结算结果选择结尾分支， 但在播放完成前不显示系统日志、结果横幅、死亡页或下一阶段界面。

撤离 3 秒 其余行动 5 秒 结果延迟揭示 动画结尾对应真实结算
决斗预览 双方对峙，中线压迫，最后一击才揭示胜负

行动总览

行动 时长 画面对象
撤离3 秒玩家角色
赠送5 秒双方角色 + 道具
施法5 秒双方角色 + 道具
邀请5 秒双方角色
决斗5 秒双方角色
暗杀5 秒双方角色

执行流程

行动确认：手动按钮、玩家 LLM 行动、NPC 行动统一进入动画流程。
规则预结算：先得到真实事件和胜负，但暂存不展示。
播放动画：overlay 拦截输入，隐藏结果横幅，按钮不可点。
结果揭示：动画结尾与真实结算一致，再追加日志和更新状态。
继续流程：死亡页、商店、选择对手或下一段对话在动画结束后触发。
关键原则：动画不是随机演出。规则层可以先算出结果，但 UI 层必须把结果藏到动画结束后。 成功、失败、反杀、法器转移、死亡等结尾都由真实结算驱动。

撤离

3s
玩家独演冷色残影安全离场
  • 玩家半身像压低亮度，背景轻微拉远。
  • 脚下出现斜向速度线，角色向画面外滑退。
  • 最后留下蓝灰残影，残影散开后才显示撤离结果。
结尾：撤离成功时画面清空；若被规则拦截，残影断裂并转红。

赠送

5s
双方表演道具移动关系变化
  • 玩家和 NPC 同时入场，道具图标从玩家侧升起。
  • 紫金契约环包住道具，双方做点头/伸手动作。
  • 图标落向接收者一侧，暖光扩散，亲近感上升。
结尾：成功时道具归入目标侧；失败时图标在中线轻震、暗淡或退回。

施法

5s
双方表演道具核心高悬念
  • 道具悬在中线，符文围绕图标快速旋转。
  • 前 3 秒只给剪影、暗红闪光和音画脉冲。
  • 最后符文命中或偏转，才显露施法成败。
结尾：成功时 NPC 侧法器光点被吸向玩家；失败时道具滑入 NPC 侧。

邀请

5s
双方表演盟约线信任悬念
  • 双方相对站定，中间浮现不稳定盟约印章。
  • 前 3 秒印章忽明忽暗，角色缓慢靠近又停住。
  • 最后盟约线稳定或断裂，映射真实邀请结果。
结尾：成功为绿色金边稳定连接；陷阱/失败则线条断裂并转暗红。

决斗

5s
双方表演中线对峙胜负揭示
  • 画面中线切开双方阵地，角色进入低身对峙。
  • 刀光、冲刺残影、定格闪白连续制造压迫。
  • 最后一击压过中线，才展示谁赢得决斗。
结尾：玩家胜则玩家侧推进并夺取光点；玩家败则 NPC 侧压制、玩家侧碎裂。

暗杀

5s
双方表演低光窥视命中/防御
  • 边缘黑幕收窄，场景进入低光状态。
  • 影子移动、短促闪光、心跳式屏幕脉冲推进悬念。
  • 最后一瞬给出穿刺命中或防御纹路亮起。
结尾：成功时攻击影穿过目标；失败时目标防御纹震开攻击方。

建议实现入口：Godot UI 新增 ActionAnimationOverlay，挂载在 dialogue HUD 上方。
