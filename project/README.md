# LiarsLand Godot Prototype

This folder contains the Godot 4.6.2 project for 《骗子大陆》.

The current main mode is a rules-judged LLM narrative adventure slice. The older keyword induction duel is kept behind `game.debug_keyword_mode`.

## Run

Open `project.godot` with:

`D:\AIProjects\CodexProjects\Tools\godot\Godot_v4.6.2-stable_win64.exe`

The web build uses a local proxy server so API keys are never bundled into the browser package.

## Configure LLMs

Edit `config.local.json`.

- `player_llm`: OpenAI-compatible chat completion endpoint for the player character.
- `npc_llm`: OpenAI-compatible chat completion endpoint for NPCs.
- `opponent_llm`: legacy fallback used when `npc_llm` is not configured.
- `game.use_mock_llm`: set to `false` to call real LLMs in desktop mode. The web build calls the local proxy by default.
- `game.debug_keyword_mode`: set to `true` to open the legacy keyword duel debug screen.

## Project Structure

- `scripts/main.gd`: startup and mode selection only.
- `scripts/core/`: state, chapter loading, and rules.
- `scripts/llm/`: chat client and prompt construction.
- `scripts/ui/`: adventure screen, layout, and debug mode.
- `data/chapter_01.json`: first playable chapter data.

## Run Web Build

Recommended one-command local web launch:

`.\start.ps1`

Or double-click:

`start.bat`

The start script exports the Godot Web build, starts the local static/proxy server, and opens the game URL.

Useful options:

- `.\start.ps1 -SkipExport`: reuse the existing `web/` build.
- `.\start.ps1 -NoOpen`: start the server without opening a browser.

Manual flow:

1. Export the Godot web build.
2. Start the local proxy/static server:

`python tools/serve_web.py`

Open:

`http://127.0.0.1:8097/index.html`

The proxy reads `config.local.json` on the server side and forwards `/api/chat` requests to the configured OpenAI-compatible endpoints.

## Generate Assets

Placeholder PNGs are generated by:

`python tools/generate_placeholder_assets.py`

Final AI art assets are generated during development in the Codex client, then copied into:

`assets/generated/`

Character portraits are expected to be transparent PNGs. Prompt records live at `assets/generated/prompts.md`.
