# 对话进行中 UI 布局概念 v1

对应图：`dialogue_in_progress_layout_v1.svg`

## 布局判断

当前游戏的核心不是玩家手动输入对白，而是观察 AI 角色与 NPC 的自动对话，并判断情报、风险、行动倾向。因此对话进行中界面应避免把底部做成传统输入框，而应该分成三层：

- 中央舞台：保留角色立绘、场景背景、当前发言方和关系温度，让“正在谈判”有戏剧感。
- 右侧常驻情报栏：显示 NPC 公开资料、亲近度、敌友判断、行动风险、线索卡和法器目标，避免玩家频繁开抽屉。
- 底部对话流：只放最近对白、系统发现、交易确认等即时内容，完整历史进入弹窗。

## 建议实现要点

- 顶栏固定显示章节、回合、字数预算、能量和 LLM 状态。
- 对话中右侧信息栏常驻，不再默认隐藏关键状态。
- “行为文件”和“历史记录”继续作为抽屉/弹窗，适合长文本。
- 对话流最多显示最近 2-4 条，避免挤压角色舞台。
- NPC 赠礼、交易、暴露身份等重要事件，在中央舞台上方短暂弹出确认/提示。
- 行动倾向只展示 AI 预测或即将执行的结果，不做成玩家手动选择按钮，以符合当前设计。
