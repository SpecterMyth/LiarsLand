# 对话进行中 UI 布局概念 v2：极简舞台版

对应图：`dialogue_in_progress_layout_v2_minimal.svg`

## 核心原则

参照 `arts/concepts/dialogue_scene_two_boxes_v1.png`，对话进行中的主界面应该优先展示：

- 两个角色
- 当前场景
- 当前对白
- 最近几句对话过程

除了顶部标题栏保留一个最重要的信息外，其余系统内容全部收进按钮。玩家需要看情报、背包、历史、行为文件、角色状态时再点开，关闭后回到纯粹的对话舞台。

## 建议布局

- 顶部标题栏：只显示一个关键状态，例如“绯尾侯爵正在回应”“身份暴露风险上升”“本轮交易待确认”。
- 左侧圆形按钮：情报、背包、历史。
- 右侧圆形按钮：行为文件/规则、状态、设置。
- 中央区域：完整留给场景背景与左右角色。
- 上层对白框：当前发言，位置更靠中上，强调正在说的话。
- 下层对白框：最近 2-4 条对话过程和系统事件。

## 弹层规则

- 情报、背包、状态：点击后使用半透明侧边弹层或整屏 overlay。
- 历史：点击后打开完整对话记录。
- 行为文件：点击后打开可编辑大面板，但不常驻占用主画面。
- 交易/赠礼/身份暴露：作为临时确认浮层出现，结算后自动收起。

## 与 v1 的区别

v1 强调常驻情报栏，适合偏策略面板的玩法；v2 强调沉浸式对话舞台，更符合现有概念图。按你的新方向，后续实现应以 v2 为主。
