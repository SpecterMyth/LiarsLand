# 对话进行中 UI 布局概念 v3：右侧按钮与姓名牌

对应图：`dialogue_in_progress_layout_v3_right_buttons.svg`

## 本版调整

- 角色名字放在对话框上沿，并叠加在对话框边框上。
- 姓名牌靠近对应角色一侧：玩家在左，NPC 在右。
- 所有按钮集中到屏幕右侧。
- 按钮改为方形图标按钮，并保留两个中文字标签。
- 右侧角色整体略微左移，为右侧按钮列让出空间。

## 主界面原则

顶部只保留一个重要状态，例如当前说话者、警报、交易确认或 LLM 状态。其余信息通过右侧按钮打开，默认画面仍以两个角色、场景和对话框为主。

## 落地建议

在 Godot 实现时，右侧按钮可使用现有 `icon_affinity.png`、`icon_char_budget.png`、`icon_unknown.png`、`icon_leave.png` 等图标资源做临时占位。按钮尺寸建议固定，例如 `60x60` 或 `64x64`，下方两字标签直接放在同一按钮内，避免按钮列宽度抖动。
