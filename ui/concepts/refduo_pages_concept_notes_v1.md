# 参考图双角色 UI 概念稿 v1

本组概念稿使用 `arts/final_references/dialogue_scene_flat_clash_v1.png` 中的两位角色作为统一视觉锚点：

- 左侧红狐：玩家代理、选择确认、升华主体。
- 右侧灰狼：主要对手、商店竞买压力、统治赛跑对照。

产出文件：

- `round_start_opponent_select_refduo_v1.svg`：每回合开始的对手选择页。
- `shop_page_refduo_v1.svg`：商店页面。
- `ascension_page_refduo_v1.svg`：升华页面。
- `dominion_page_refduo_v1.svg`：统治页面。

共同设计语言：

- 1600x900 横屏概念稿，延续现有 UI 概念文件规格。
- 粗黑描边、尖拱、斜切卡框、金色名牌、红/紫/青绿色夜景对比。
- 不使用项目现有角色资产，只用参考图中红狐与灰狼的轮廓、配色和服装气质做矢量化 UI 草图。
- 重要状态尽量放在金色或红色斜切面板上，普通信息放在黑底金边面板里。

落地建议：

- Godot 中可先把这些 SVG 当作布局草图拆成 Control 节点：顶部状态条、中心卡组、左右角色压力栏、底部提示栏。
- 角色插画最终应重绘为同一扁平粗描边风格，避免混用当前项目中更写实的半身像。
- 商店、升华、统治三页建议复用同一套法器卡组件，只改变卡片状态：可购买、已满足、缺失、对手威胁。
